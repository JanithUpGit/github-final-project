# Simple Interest Calculator

A simple Bash script to calculate simple interest based on the principal amount, annual interest rate, and time period in years.

## Description

This project is part of the micro-finance startup initiative to transition code management to Git and GitHub. The script takes user input for principal amount, interest rate, and time period, then computes the simple interest using the formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$
